## TASK-4.2 Compare compiler and interpreter

| Point | Compiler | Interpreter |
|-------|----------|-------------|
| When translation/execution happens | Translates the entire source code before execution | Executes instructions during runtime, generally one at a time or in smaller units |
| Typical output | Often generates an executable file or machine code | Usually executes the code directly without creating a separate executable file |
| One example | C and C++ (commonly compiled languages) | Python (commonly interpreted) |
| One advantage | Compiled programs can execute faster because translation is completed beforehand | Makes testing and debugging easier because code can be executed without a separate compilation step |

-------------------------------------------------------------------------------------------------------

## 1. Command used to run python 
--> python3 hello.py

## 2. understanding about program execution 
--> Program execution is the process of running a program to perform the instructions written by the programmer. The computer uses a compiler or interpreter to translate or execute the source code so that the processor can carry out the instructions. When a program runs successfully, it produces the expected output. For example, running python3 hello.py executes the Python program and displays Hello from Python in the Terminal.
